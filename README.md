# 매티스토 (mathisto)

**아이들이 수학과 물리학에 친해지도록 돕는 주간 매거진이에요.**
처음 들으면 복잡하고 어려워 보이는 원리를, 자연 속 사례와 실제(혹은 실험 중인) 공학 응용까지 이어서 쉽게 풀어드려요.
글마다 직접 슬라이더를 움직이며 실험해볼 수 있는 인터랙티브 데모가 함께 있어요.
