# Mathisto

> **Understand the principle. Simulate it. Engineer it.**  
> **원리를 이해하고, 코드로 실험하고, 공학으로 확장합니다.**

**Mathisto**는 수학과 물리의 원리를 단순히 공식을 암기하는 대신,  
**직관적으로 이해하고, 수학적으로 표현하고, 코드로 직접 실험해보는 프로젝트**입니다.

그리고 거기서 한 걸음 더 나아갑니다.

우리가 배우는 수학과 물리의 원리가 실제 세상에서 어떻게 사용되었으며,  
어떤 아이디어를 거쳐 오늘날의 **과학·공학 기술로 발전하고 응용되었는지** 탐구합니다.

---

## 🔍 How Mathisto Explores

Mathisto의 각 주제는 다음 과정을 따라갑니다.

```text
현상 (Phenomenon)
      ↓
직관 (Intuition)
      ↓
수학적 모델 (Mathematical Model)
      ↓
코드 (Code)
      ↓
시뮬레이션 (Simulation)
      ↓
한계와 현실 (Limitations & Reality)
      ↓
공학적 응용 (Engineering)
```

### 1. Phenomenon — 왜 그럴까?

우리 주변에서 발견할 수 있는 현상과 질문에서 시작합니다.

> 구름은 왜 흰색일까?

### 2. Intuition — 먼저 직관적으로 이해하기

복잡한 공식부터 시작하지 않습니다.

그 현상이 **왜 일어나는지** 그림과 간단한 설명을 통해 먼저 이해합니다.

### 3. Mathematical Model — 자연을 수학으로 표현하기

현상을 설명하는 데 필요한 수학과 물리 법칙을 찾아  
현실을 단순한 **수학적 모델**로 표현합니다.

### 4. Code — 수식을 코드로 옮기기

수학적 모델을 Python 등의 코드로 구현합니다.

공식이 실제 계산 과정에서 어떻게 동작하는지 확인합니다.

### 5. Simulation — 움직여보기

조건과 변수를 바꾸며 직접 실험합니다.

```python
velocity = 20
angle = 45
gravity = 9.81
```

숫자를 바꾸면 결과는 어떻게 달라질까요?

### 6. Limitations & Reality — 공식을 의심하기

교과서의 공식은 현실을 단순화한 모델입니다.

공기저항, 마찰, 측정 오차 등 현실의 조건을 하나씩 추가하면서

> **우리가 만든 모델은 현실을 얼마나 잘 설명할까?**

를 살펴봅니다.

### 7. Engineering — 그래서 무엇을 만들었을까?

마지막으로 이 원리가 실제 공학에서 어떻게 사용되고 발전했는지 살펴봅니다.

```text
수학적 원리
    ↓
물리 법칙
    ↓
실험과 발견
    ↓
공학적 해결
    ↓
현대 기술
```

하나의 작은 원리가 때로는

**센서 → 로봇 → 자동차 → 항공기 → 우주선**

같은 거대한 기술로 발전하기도 합니다.
